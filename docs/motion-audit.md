H1 audit, 2026-10-07. This inventory follows the approved original header, CSS hero, Bento/shelves and compact Footer Dock direction. It records intentional differences as well as repaired gaps; static content is not automatically a missing animation.

## Ownership and lifecycle

Entrance motion uses scoped `useEntranceAnimation`/GSAP matchMedia. Normal scrolling reveals run once at `top 85%`, for 0.6 seconds with `power2.out`. Shared wrappers may rise 30px; categories and project-card wrappers fade only so CSS retains hover-transform ownership. Reduced motion and unmount revert GSAP contexts and triggers. Server HTML is readable without JavaScript; the initial startup deadline restores content if application chunks are deferred or blocked. The initial CSS hiding gate exempts focused descendants, covering the frame before a live motion-media callback runs; existing animation owners also finish a focused target immediately.

## Findings and repairs

The subsequent H2 trial adds the owner-selected typography and combined assembly/request illustration to Home's About section. Its source, build, browser checks and bundle measurements are recorded separately in [motion studies](motion-studies.md). This inventory reflects that local trial; the H1 verification results below retain their original build and scope.

The audit confirmed missing Experience Education/Certifications heading reveals, Contact rows/fields triggered as a group before later mobile content entered view, incomplete form reveal ownership, and removed Open Source card fades. CSS hover/press motion on Home, Contact and project shells also bypassed reduced-motion gates. Contact particles respected the preference only when spawned and continued after a live change.

The project-sheet audit separately reproduced two stuck Close attempts in 32 bounded runs: the URL traversed back but the dialog remained mounted and scroll-locked. Event/URL traces establish a missing native-history-to-local-selection synchronization path; precise initial Next history-patch scheduling remains an inference. The repair uses native popstate synchronization, preserving the existing guarded query controller and normal history semantics.

Integration checks caught two additional focus issues. CSS can hide a focused control for a frame before a live motion-media callback starts; the focused-descendant exception covers that gap. Finishing a translated control during pointer focus can also move it between pointer-down and pointer-up, causing the click to miss. This was reproduced on the Home closing CTA, Contact submit and a partially revealed Contact Website link. These actionable targets now fade in place, with actual early-pointer activation regressions covering navigation, validation, mocked submissions and a locally intercepted Website popup.

Before measurements, failed attempts and candidate patches are retained in the local audit evidence. The owner approved publishing the cumulative H1/H2 preview from `feat/animation-audit` on 2026-10-07. Publication checks are in progress and the known intermittent Close observation remains unresolved. H1's original verification checkpoint uses build `RP5YoRrHMglEcm8vxMAB3`; subsequent Home and branding changes have separate evidence.
