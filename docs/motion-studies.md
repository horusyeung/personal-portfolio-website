## Research basis

Selected current examples favour understandable content with deliberate expressive moments: [Linear's 2026 refresh](https://linear.app/now/behind-the-latest-design-refresh) reduces competing emphasis, while [Stripe's Harbor prototype article](https://stripe.dev/blog/harbor-stripes-ai-assisted-prototyping-tool) shows a UI animation developed through a working prototype. This is an inference from those examples, not a claim about the entire industry. [Apple's motion guidance](https://developer.apple.com/design/human-interface-guidelines/motion) informs purpose, optional motion and interruption; it does not establish an Apple-preferred third-party web library.

The trials use CSS, SVG, [Web Animations](https://developer.mozilla.org/en-US/docs/Web/API/Web_Animations_API) and one feature-detected [View Transition](https://developer.chrome.com/docs/web-platform/view-transitions/same-document). They need no extra runtime. The production site already uses GSAP, which remains an option for coordinating a selected sequence. Its [licence is Webflow's no-charge proprietary standard licence](https://webflow.com/legal/product-terms), rather than MIT. [Motion](https://github.com/motiondivision/motion/blob/main/LICENSE.md) is an MIT alternative; no demonstrated requirement currently justifies adding it.

Same-document View Transitions shipped in [Safari 18](https://webkit.org/blog/15865/webkit-features-in-safari-18-0/). Safari 17 gets the direct state update; automated modern WebKit results do not verify native Safari 17. Platform support and third-party APIs must be rechecked if a candidate is selected for production.

The owner-requested Horvault reference contributed general lifecycle, bounded spotlight, named-transition and deterministic-demo lessons. Its private branding, assets and product data are not used in these studies.
